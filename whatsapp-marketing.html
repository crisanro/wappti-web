Preguntas Frecuentes

¿Me pueden bloquear el número de WhatsApp?

No. Como nosotros utilizamos la API Oficial de Meta (WhatsApp Business API), los envíos masivos se realizan bajo las normativas legales de Meta, evitando bloqueos a tu línea personal.

¿Puedo adjuntar imágenes a mi campaña?

¡Sí! Las campañas de Wappti soportan el envío de imágenes atractivas, lo cual es ideal para flyers de descuentos, promociones del mes o nuevos catálogos.

¿Cuántos mensajes puedo enviar a la vez?

Puedes enviar a cientos de clientes simultáneamente. El sistema encola los mensajes y los envía respetando los límites de velocidad de la API oficial para asegurar una entrega exitosa al 100%.

¿Necesito conocimientos técnicos?

Para nada. La interfaz está diseñada para que cualquier persona pueda escribir el texto, seleccionar a los clientes y presionar "Enviar" en menos de 3 minutos.
